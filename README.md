Teacher-Student File Management Platform
Introduction
This project is a web-based file management and assignment platform designed to facilitate interaction between teachers and students. The system allows teachers to manage course materials and assignments, while providing a structured environment for students to submit their work and receive feedback. The platform is built using a PHP backend and a MySQL database, with a dynamic frontend powered by HTML, CSS, JavaScript, and Bootstrap.

Key Features
Teacher/Admin Capabilities
File and Document Management: Teachers can add, update, and delete files and documents, organizing course materials with full control.

Folder Creation: The ability to create folders to group and categorize related files and assignments for better organization.

Student Management: Teachers can add students to the platform by entering their email addresses and can map them to specific classes and batches.

Assignment Submission Review: Teachers can review submitted student documents and choose to accept or decline them.

Rejection Feedback: If a submission is declined, the teacher is required to provide a reason, which the student can view.

Transaction History: A comprehensive log tracks all submission and review activities, including dates of submission, acceptance, or rejection, and the reason for any rejections.

Student Capabilities
User Authentication: Students can securely log in to their personal accounts.

File Submission: Students can submit files or documents for assignments assigned by their teacher.

Resubmission: If a submission is rejected, students are required to review the rejection reason and resubmit the corrected file.

Technology Stack
Backend: PHP

Database: MySQL

Frontend: HTML, CSS, JavaScript, and Bootstrap
